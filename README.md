# Programming_Languages_Project_1

To run the code first (only for windows os):
- Install Beef Programming Language for Windows using this link: https://www.beeflang.org/setup/BeefSetup_0_43_5.exe
  
- (Second step if Microsoft Visual Studio 2022 Build Tools is not installed on your computer already) run this in Command Prompt: winget install Microsoft.VisualStudio.2022.BuildTools --override "--add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"

- Open the Beef IDE and add the file "updatedProgram.bf" from this github repo and then press F5 to run the code

- Test the code by entering the instructions (for example: begin SQR A1-B2 end)
